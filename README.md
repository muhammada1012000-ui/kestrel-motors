# Kestrel Motors

A website for a used-car dealership. It's a single page with no build step.

- Inventory you can filter and sort, with a detail view and test-drive booking for each car
- Monthly payment calculator
- Trade-in offer form
- Location, contact details and opening hours
- Works on phones, with light and dark themes

Open `index.html` in a browser to view it.

The business name, contact details and cars are sample content. The forms don't send data anywhere yet.
